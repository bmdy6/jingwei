# 知识库整理的后续方向

这是一份设计备忘录，不是已交付功能清单。`organize_notes`、笔记索引和任务队列已有代码；本轮未使用真实个人笔记验收自动整理。

## 按用户指令整理

先列出目标文件，再读取正文、生成修订、展示差异、取得写入授权，最后备份和回读。现有工具有文件写入与备份路径，但长期笔记整理应另做小样本验收，不能从单元测试推断正文质量。

## 定时巡检

可以用任务队列发起索引或候选整理任务。先只生成建议清单，保留原文。需要改变文件位置或内容时，再验证权限、取消和失败恢复路径。

## 建立关联

后续可从已有全文和向量检索中推荐相关文章，给出来源、理由与置信边界。先验证推荐质量，再考虑自动写入双链；暂不承诺完整知识图谱或避免遗忘。
