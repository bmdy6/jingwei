# 技能系统设计备忘录

本页保留可复用的设计方向，不表示所有流程已经实现。

## 当前入口

- `agent/skills/manager.py` 管理技能；`agent/core/prompt_builder.py` 根据触发词列出相关技能索引。
- `record_skill_usage` 记录使用结果，达到配置阈值时可将数据库中的经验条目标为技能。
- `agent/evolution/` 包含会话后反馈、规则和任务模式提炼。模型输出的内容需要复核。
- `agent_memory/` 是运行时资产，随项目首次运行创建；仓库仅保留空目录标记。

## 可继续发展的方向

1. 任务澄清：复杂任务开始前记录目标、验收条件和工具边界。
2. 方案比较：需要取舍时生成候选方案，再由用户选择。
3. 流程沉淀：保存经过重复验证的步骤、适用条件和失败恢复方法；不把单次成功当成通用技能。
4. 笔记关联：仅索引用户明确配置的目录，为引用内容保留文件来源。

未来如要接入文档转换器或浏览器检查，应先增加局部验证，再纳入默认工具集。这里的建议不构成性能、可靠性或自动学习效果的承诺。
